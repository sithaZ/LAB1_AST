# Lab04 - Playwright E-commerce UI Automation

## Description
This lab implements an E-commerce UI Automation framework using Playwright.

## Features
- Page Object Model
- Login automation
- Add product to cart
- Cart verification
- Screenshot capture
- HTML test reporting

## How to Run

Install dependencies:

npm install

Run tests:

npx playwright test

Open HTML report:

npx playwright show-report
